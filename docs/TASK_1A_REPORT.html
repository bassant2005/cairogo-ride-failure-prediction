3. Distributional Disparity & Selection Bias Risk

Dropping unmatched rows (a common pitfall in naive data preparation) would have introduced target selection bias. The ride request failure rate in the unmatched subset is markedly higher than in the remainder of the dataset:

Partition Total Requests Failed Requests Failure Rate
Unmatched Requests (Legacy Zones) 3,243 624 19.24%
Matched Requests (Standard Zones) 25,001 4,399 17.60%
Entire Dataset (Benchmark) 28,244 5,023 17.78%
Key Finding: Requests originating in legacy zones experienced a failure rate +1.64% higher than standard zones. Discarding them would artificially deflate training failure rates and undermine model sensitivity for peripheral and suburban regions.

4. Authoritative Remediation Strategy

The mapping was achieved by referencing the explicit legacy_name attribute provided in zones.csv, ensuring zero manual guesswork: 

# Vectorized legacy-to-standard mapping
legacy_mapping = zones.set_index("legacy_name")["zone_name"].to_dict()

# Remediation applied across both pickup and dropoff attributes
trips["pickup_zone"]  = trips["pickup_zone"].replace(legacy_mapping)
trips["dropoff_zone"] = trips["dropoff_zone"].replace(legacy_mapping)

# Verification
assert len(set(trips["pickup_zone"]) - set(zones["zone_name"])) == 0
